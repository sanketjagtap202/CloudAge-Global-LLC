start-dfs.sh is a shell script provided by Apache Hadoop that starts all the core Hadoop Distributed File System (HDFS) daemons on your cluster.

When you execute start-dfs.sh, it reads your configuration files (hdfs-site.xml, core-site.xml, workers or slaves) and launches three key background processes:

NameNode: The master server that tracks the directory tree and metadata for all files stored across the cluster.

DataNodes: The worker nodes that store and retrieve the actual data blocks.

Secondary NameNode: The helper service that periodically takes snapshots of the NameNode's metadata to prevent data loss and assist with housekeeping.

	SSH Commands in sequence:
ssh -v localhost
	# 1. Install SSH server cleanly
sudo apt update
sudo apt install -y openssh-server
 	# 2. Start and enable the SSH service
sudo systemctl enable --now ssh || sudo service ssh start
	# 3. Create SSH directory if missing and set correct permissions
mkdir -p ~/.ssh
chmod 700 ~/.ssh
	# 4. Generate a fresh key (overwrites old one safely if needed)
rm -f ~/.ssh/id_rsa ~/.ssh/id_rsa.pub
ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa
	# 5. Authorize the public key locally
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
	#6. Automatically add localhost to known_hosts (prevents interactive prompt)
ssh-keyscan -H localhost >> ~/.ssh/known_hosts 2>/dev/null
ssh-keyscan -H 127.0.0.1 >> ~/.ssh/known_hosts 2>/dev/null
ssh-keyscan -H $(hostname -I | awk '{print $1}') >> ~/.ssh/known_hosts 2>/dev/null
